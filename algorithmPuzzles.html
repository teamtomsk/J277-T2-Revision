Build it. Check it. Explain it.

Small steps, stronger algorithms.

Six short puzzles to practise decisions, loops and careful boundaries. Drag a card into a gap — or select a card, then select the gap. Two cards in each puzzle will not be used.

First time? Start here
  1. Read the task. Follow the arrows or read the code from the top.
  2. Choose a card, then a gap. Keyboard users can Tab to each and press Enter.
  3. To change a block, drop another card over it. Move a placed block by dragging it, or use “Return selected block”.
  4. Select a gap or use the step selector for a hint. “Next guided step” places one correct block and explains it.
  5. Check your answer, then trace an example. Finally try writing the algorithm on paper without the cards.

Flowchart shapes, arrows and code indentation are supplied. In an exam you may need to create these yourself. This activity checks the supplied scaffold; other valid algorithms may exist.
